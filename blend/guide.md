# Blender Quick Guide

## cut
1. Create the breakdown sheet
2. Apply the material
3. Tab - convert to mesh
4. k - knife tool (see tool modifier keys on the bottom of the window)
5. s - shows measurements
6. a - angle constraint snap on cut tool
7. enter/esc - apply/cancel changes

## seperate
1. Mesh > Split (Alt + M) > Faces & Edges by Vertecies
2. Mesh > seperate (p) > by lose parts
3. delete unwanted meshes
4. Right click on seleced object > Set Origin > Origin to Geometry

## Move origin/pivot
1. select item
2. click 'tool' tab on the right of the viewport
3. tick 'origins'
4. use go/move tool (g) to position

## linking
1. select child, then parent
2. Object > Parent > Object (Ctrl + P)

## layout
Nothing special, layout your prop
Scale camera to fit

## Check-list
Before animating, render out a single frame, ensure it looks good ingame.
Make texture/outline adjustments before animating is much easier.
